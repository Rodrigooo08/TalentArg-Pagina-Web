# Talent ARG - prototipo web

Estructura:
- index.html  -> página principal (cabecera, menú, contenedor)
- css/styles.css -> estilos (paleta crema / durazno / café / naranja)
- js/app.js -> rutas (#/clientes, #/elegir, #/usuario, #/empresa...), carrusel y formularios
- assets/img/ -> imágenes extraídas del PDF

Cómo probar: abrí index.html en el navegador (doble clic). No requiere servidor.
Los registros se guardan en localStorage (solo demostración).
